# 🎓 Exploring Coursera: Data Benchmark & Course Distribution

## 📌 Overview
Proyek ini bertujuan untuk menganalisis dan menguraikan katalog kursus platform **Coursera**. Melalui pembersihan data menggunakan **Python** dan visualisasi interaktif di **Looker Studio**, analisis ini memberikan gambaran umum terkait distribusi kategori kursus, tingkat kepuasan pengguna (*rating*), serta variasi tipe program pembelajaran yang tersedia.

---

## 🛠️ Tech Stack & Tools
- **Data Cleaning & Processing:** Python
- **Data Visualization & Dashboarding:** Looker Studio
- **Documentation:** Markdown

---

## 📊 Key Performance Indicators (KPIs)
- **Total Courses Analyzed:** 186 kursus dalam dataset katalog.
- **Average Course Rating:** **4.73 / 5.00** — Menunjukkan tingkat kepuasan pengguna yang sangat tinggi terhadap materi dan pengajar di Coursera.

---

## 💡 Key Insights & Findings

### 1. Market Distribution & Top Categories
Kurikulum Coursera sangat didominasi oleh bidang IT, Teknikal, dan Desain Produk Digital:
- 🛠️ **Support and Operations:** 26 kursus (Kategori terbanyak).
- 📊 **Data Analysis & Cloud Computing:** Masing-masing 22 kursus.
- 🎨 **Design and Product:** 20 kursus (Mencakup UX/UI design).
- 🌌 **Physics and Astronomy:** 18 kursus.
- 💼 **Business Essentials & Networking:** Masing-masing 14 kursus.

### 2. Standard Kualitas Tinggi
Rata-rata rating **4.73** mengindikasikan konsistensi standar kualitas pengajaran di seluruh kategori program.

### 3. Eksplorasi Katalog Interaktif
Dashboard ini dilengkapi fitur *filter* interaktif untuk memilah katalog berdasarkan tipe program (*Course, Specialization, Professional Certificate, Guided Project*) serta tabel rincian judul dan rating spesifik.
